# 인테이크

다른 프리셋의 인테이크는 빈 워크스페이스를 문답으로 채운다. 이 프리셋의 재료는 대개 이미
있다. 아이디에이션 대화 자체가 재료라서, 인테이크의 주 경로는 묻기보다 뽑기다. 대화에서
문장을 뽑아 측면과 출처를 붙이고 그 표로 첫 인스턴스를 심는다.

| 모드 | 언제 | 재료 |
|---|---|---|
| A. 진행 중 대화 | 대화 중 프로젝트급 개념이 드러났을 때 | 이 세션의 대화 |
| B. 기존 문서 | 이미 뭉친 문서를 분해할 때 | 원 기록, 기획서, 회의록 |
| C. 빈 시작 | 사용자가 이름만 대고 시작할 때 | 짧은 문답 |

## 문장 인벤토리

모드 A 와 B 는 같은 표를 만든다. 쓰기 전에 표부터 만든다. 표 없이 쓰기 시작하면 첫 측면
문서에 이것저것 들어가고, 그것이 이 프리셋이 막으려는 실패다.

| # | 문장 (요지) | 측면 | 출처 | 날짜 | 번복 |
|---|---|---|---|---|---|
| 1 | 1차 타깃은 직장인 커플 | 고객 | 확정 | 2026-09-24 | |
| 2 | 동물 잠옷에 전용 모션을 묶어 판다 | 과금 | 제안 | | |
| 3 | 두 번째 캐릭터부터 유료 -> 생성 무료 + 슬롯 과금 | 과금 | 확정 | 2026-09-24 | 옛 값, 이유 |
| 4 | 1/6 은 면적 기준인가 폭 기준인가 | 경험 | 질문 | | |

출처 판정 규칙.

- 확정: 사용자가 말한 문장, 또는 에이전트 제안에 사용자가 "그걸로 하자", "좋아요, 그렇게"
  처럼 채택을 표한 문장. 채택 발화가 없으면 확정으로 올리지 않는다.
- 제안: 에이전트가 낸 선택지, 추천, 아이디어. 사용자가 반응하지 않았거나 "생각해 볼게요"
  라고 한 것도 제안이다. 사용자가 에이전트 수치를 조건문으로 인용한 것("배송비가 3~4천
  원이면")도 제안으로 남긴다.
- 밀려남: 에이전트 제안이 다른 안의 채택으로 밀려났다. 기각과 같게 다룬다.
- 기각: 사용자가 명시적으로 거절한 제안. 표에는 남기되 주제 문서에는 쓰지 않는다. 방향을
  정한 기각이면 결정이력에 한 줄.
- 질문: 누가 물었고 아직 답이 없는 것. 열린 질문 절로 간다.
- 에이전트가 조사해 보탠 사실(규제, 가격, 경쟁사)은 제안 절에 출처와 함께 둔다.

번복 판정: 같은 측면의 같은 대상에 대해 뒤의 확정 문장이 앞의 확정 문장과 다르면 번복이다.
주제 문서의 확정 절에는 뒤의 값만 적고, 결정이력에는 옛 값과 이유를 함께 적는다. 이유가
대화에 없으면 "이유 미기록" 으로 남기고 지어내지 않는다.

## 표에서 구조로

1. 측면 열을 모아 측면마다 한 줄 정의를 쓴다. 두 측면의 정의가 같은 문장으로 묶이면
   합친다. 한 측면의 문장들이 정의 둘로 갈리면 나눈다.
2. 측면을 축에 배정한다([[product-ideation-layout]] "축 고르기").
3. 측면 안에서 주제를 나눈다. 한 측면에 주제가 하나면 문서 하나, 정의가 갈리는 주제가
   여럿이면 문서 여럿이다. 타이니어스의 경험 측면은 화면구성, 감정과상태, 공간 셋이다.
4. 날짜와 번복 열로 결정이력을 채운다.
5. 문장에서 뜻을 정한 명사(슬롯, 공간 모드, 의상 프리셋)를 뽑아 용어를 채운다.

## 되묻는 경우

기본은 묻지 않고 만든다. 생성은 되돌릴 것이 없다. 다음 셋만 AskUserQuestion 으로 묻는다.
대화 중이라면 대화 흐름을 끊지 않도록 사용자의 다음 발화에 답한 뒤에 한 번에 묻는다.

- 축 경계: 사업 / 서비스 외의 축을 골랐고 경계 문장이 두 갈래로 써질 때. 선택지는 후보
  경계 문장 둘.
- 출처 모호: 채택 발화로 읽힐 수도 아닐 수도 있는 문장("그것도 괜찮네")이 결정의 핵심일
  때. 선택지는 확정 / 제안 유지.
- 번복 여부: 뒤의 문장이 앞의 결정을 바꾼 것인지 다른 경우를 말한 것인지 갈리지 않을 때.

## 모드 C. 빈 시작

사용자가 "새 프로젝트 X 시작하자" 처럼 이름만 줄 때다. 뼈대(프로젝트 노트, 축 둘, 결정이력,
용어)를 먼저 만들고 한 라운드만 묻는다. 모르는 답은 비워 두고 대화로 채운다.

| 질문 | 선택지 예 | 채우는 곳 |
|---|---|---|
| 한 줄로 무엇인가 | 자유 입력 | 프로젝트 노트 `definition` |
| 누구를 위한 것인가 | 직장인, 학생, 팀, 기업, 아직 모름 | 사업/고객 |
| 어떻게 돈을 버는가 | 구독, 건별, 광고, 아직 모름 | 사업/과금 |
| 무엇을 먼저 만드는가 | 웹, 모바일, PC, 아직 모름 | 서비스/경험 |

"아직 모름" 을 고른 칸은 폴더를 만들지 않는다. 대화에 그 측면이 처음 나올 때 만든다.
